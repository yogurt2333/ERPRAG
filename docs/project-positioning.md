# 项目定位：快消经销 ERP Agent

用户确认的来源链路：领雁科技工作中接触企业内部 ERP / AI 应用场景，观察到
传统系统交互门槛；个人项目结合家庭快消经销业务，研究自然语言业务交互。
不得将个人项目交付、家庭业务试验或 ERPNext 功能归入公司项目成果。

## 责任边界

- ERPNext：开源业务底座，提供客户、供应商、商品、仓库、采购、销售和库存等模型。
- 个人工作：部署和配置快消经销演示业务；开发 TypeScript/Node + Pi 工具与审计。
- 已完成：合成销售价格审计、检索、确定性说明、运行时边界及测试。
- 已完成：Windows 本机 ERPNext 16.35.0 部署、站点创建和 HTTP 健康验证。
- 当前边界：已验证 ERPNext 业务页面与采购演示数据，Agent 仍使用合成数据适配层；
  ERPNext API 到审计 Agent 的真实数据接入尚未完成。
- 后续研究：最小权限、HITL 人工确认、业务操作审计日志、独立评测集。

使用 ERPNext 后，推荐表述“基于 ERPNext 配置快消经销业务模型并开发 Agent
交互与审计能力”，不表述为从零复刻整个 ERP，也不声称已有生产使用效果。
现有 28 项测试只覆盖原个人审计程序，不覆盖 ERPNext 部署和集成。

## 2026-09-27 规划调整

后续产品方向改为参考 ERPNext 业务流程、独立实现适配 2 核 2GB 的单用户轻量
经销 ERP；不复制 ERPNext 源码或数据库。该方向目前只有领域词汇、ADR 和 MVP
设计，尚无账本内核、Hermes 写入、Web/PWA、2GB 压测或双线试运行证据。
完整边界见 [轻量 ERP MVP 设计](lean-erp/MVP-DESIGN.md)。先前 ERPNext 本地部署
仍是已完成的学习实验，不等于新方向的实现，也不再是计划中的生产业务核心。
