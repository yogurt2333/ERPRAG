# ADR 0010: Use remote inference with data minimization

Accepted. Hermes may send the operator's current message and the minimum necessary
business context to an external model API. Deterministic local tools own validation,
money, inventory, retrieval acceptance and all writes. The system never sends whole
tables, archives, backups or unrelated history; tool responses and logs minimize or
redact business details. Remote-model availability is not required for the ERP Web
fallback to perform deterministic operations.
